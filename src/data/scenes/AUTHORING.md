# Руководство автора библиотеки сцен

Библиотека — это ≥ 200 **микросцен** (конкретных мест/ситуаций), по одному файлу на категорию:
`home`, `city`, `food`, `nature`, `water`, `travel`, `everyday` → `src/data/scenes/<имя>.scenes.ts`.
Файл экспортирует `export const scenes: readonly SceneInput[] = [ … ]`. Тип `SceneInput` — в `src/core/types.ts`,
наборы-сокращения (`SE_ALL`, `WE_ALL`, `TI_ALL`, `TI_INDOOR` …) — в `src/data/scenes/define.ts`.
Образцы — `src/data/scenes/_examples.ts` (они проходят валидатор).

Проверка своей категории (должна быть без ошибок):

```bash
npx tsc --noEmit
npx vitest run tests/scenes.test.ts -t "данные сцен: home"   # имя категории: home | city | food | nature | water-sport | travel | everyday
```

## Поля

| Поле | Смысл и формат |
|---|---|
| `id` | kebab-case, префикс категории: `home-`, `city-`, `food-`, `nature-`, `water-`, `travel-`, `everyday-`; уникален |
| `cat` | категория (`'home' \| 'city' \| 'food' \| 'nature' \| 'water-sport' \| 'travel' \| 'everyday'`) |
| `rar` | `'c'` обычная (~55 %), `'u'` необычная (~30 %), `'r'` редкая (~15 %) |
| `ru` | русское название 4–60 символов («Кухня: утренний кофе») — показывается в интерфейсе |
| `place` | английская фраза **с предлогом места**: `in a small kitchen …`, `on a pedestrian bridge …`, `at a tram stop …` |
| `env` | `'in'` помещение, `'out'` улица, `'cov'` под навесом/полуоткрыто (остановка, терраса, вокзальный перрон) |
| `view` | что видно снаружи: `'open'` (улица/навес), `'win'` (в помещении есть окно с видом), `'none'` (глухое помещение: спортзал, метро-переход, подвал) |
| `dress` | необязательно. `'out'` — одежда определяется уличной погодой (метро, вокзал, подземный переход, торговые ряды); по умолчанию `in` для помещений и `out` для улицы |
| `se` | допустимые сезоны (`SE_ALL`, `SE_WARM`, `['summer']` …) |
| `we` | допустимая **видимая** погода (для `view: 'none'` не указывайте). Значения: `clear, partly-cloudy, overcast, rain, after-rain, fog, snow, windy, heat, frost` |
| `ti` | допустимое время: `dawn, morning, day, golden-hour, dusk, evening, night`. Для `view: 'none'` — только `TI_INDOOR` (morning/day/evening/night) |
| `act` | 3–6 действий: `[en, ru, posture, hands, flags?]` (см. ниже) |
| `out` | семейства одежды: `casual, cozy, smart, evening, sport, dance, swim, beach, ski, hiking, work, travel` |
| `fg` / `mid` / `far` | по 2–4 существительные фразы: передний / средний / дальний план |
| `det` | 3–6 мелких реалистичных деталей: строка или `[текст, условие]`; минимум две безусловные |
| `light` | характер дневного света **без солнца/погоды**: источник и геометрия («soft light from the single kitchen window») |
| `night` | искусственный свет для dusk/evening/night; **обязателен**, если во `ti` есть dusk/evening/night |
| `ang` | типичные ракурсы (3–8): `front, three-quarter, profile, back-head-turn, side, slightly-above, slightly-below, eye-level, distant, close-up, dynamic-tilt, face-limited` |
| `mirror` | `true`, только если в сцене есть настоящее зеркало (ванная, прихожая, спортзал, примерочная, студия) — разрешает селфи в зеркале |
| `glass` | `true`, если есть большое стекло/витрина/стеклянная дверь/окно трамвая/лифт — разрешает селфи в отражении |
| `solo` | `true`, если третьему лицу сложно снимать (кабинка, личное пространство) — отключает кадры «от знакомого» |
| `crowd` | `0` пусто/частно, `1` возможны случайные люди вдали, `2` без людей фона неправдоподобно (концерт, ярмарка, час пик) |
| `noTripod` | `true`, если поставить камеру невозможно (движущийся транспорт, давка) |
| `tags` | `trees, grass, pavement, stone, wood, water, sand, glass, crowd, vehicle, soil, snowbound` — для общих деталей; `snowbound` — сцена требует снежного покрова (лыжи, санки) |

### Действие `[en, ru, posture, hands, flags?]`

* `en` — **причастие на -ing без подлежащего**: «pouring coffee from a moka pot into a mug», «leaning against the doorframe with a mug in one hand». Встанет в предложение «She is …».
* `ru` — короткая русская фраза от третьего лица: «наливает кофе из гейзерной кофеварки в кружку».
* `posture` — `stand | sit | walk | move | lean | crouch` (`move` — бег, танец, прыжок).
* `hands` — сколько рук **заняты** действием (0–2). Для селфи нужна свободная рука, поэтому «два занятых» — не селфи-кадр.
* `flags` (через пробел): `obj` — внимание на предмете/деле (читает, готовит), взгляд не в камеру; `back` — стоит спиной/боком к камере (смотрит на вид); `hidden` — лицо скрыто действием (наклонилась, пьёт из бутылки).
* Нужно и **селфи-пригодное** действие (hands ≤ 1, без `obj/back/hidden`, стоя/сидя/опираясь/идя), и «чужое» (hands 2, `obj`, `back` или `hidden`).

### Условные детали

`['текст', 'условие']`, условие — токены через пробел: `w:rain,after-rain` (погода), `s:autumn` (сезон), `t:evening,night` (время).
Условия сочетаются по «И». Условие должно пересекаться с `se/we/ti` сцены. Примеры: `['puddles reflecting the shopfronts', 'w:rain,after-rain']`, `['a few fallen leaves gathered along the curb', 's:autumn']`.

## Главное правило: безусловный текст нейтрален

Всё, что не помечено условием (`place`, `act`, `fg`, `mid`, `far`, безусловные `det`, `light`), должно оставаться правдой **при любой допустимой для сцены** погоде, сезоне и времени суток.
Поэтому в таком тексте нельзя: дождь, лужи, зонты, «мокрый/влажный» (кроме сцен с тегом `water`), снег/лёд/мороз (кроме сцен только зимой), туман, солнце/луна/звёзды/закат/«золотой», вечер/ночь/утро/завтрак (если сцена не только для этого времени),
осень/весна/лето/зима, опавшие листья, почки/цветение, жару/пот, «голые деревья», «включённый свет/неон» (если сцена не только вечерняя). Валидатор проверяет это регулярными выражениями и пишет, что именно исправить.
Всё погодное и сезонное — только в **условных** `det`. Дневной `light` — без «sunlight», «golden», «moonlight»: свет по погоде и времени добавит движок.

## Содержание

* Конкретно и достоверно: настоящие бытовые предметы, фактуры, мелкая неидеальность (потёртый стол, магнит на холодильнике, цепь на велосипеде). Без пафоса и «кинематографичных» штампов.
* Только взрослые: никаких детей, подростков, школьной формы, «юного» образа. Людей на фоне упоминайте редко и только как случайных взрослых вдали.
* Без откровенного: никакого белья, наготы, эротики. Спортивная и пляжная одежда выбирается движком по `out` — в сценах её не описывайте; в `fg/mid/far/det` не описывайте одежду главной героини.
* Без брендов, логотипов, читаемых надписей, реальных людей и названий мест; достопримечательности — без имён.
* Физика и логика: бассейн — купальник/вода, лыжи — снег и зима, зонт и лужи — только в условных деталях; в каждом `place` место понятно с первого прочтения.
* Сцены внутри категории и между категориями должны заметно отличаться местом, действиями и предметами (не «ещё одно кафе»). Не копируйте действия между сценами.
* Цифры не используйте (числа словами), в конце фраз точки нет, фразы начинаются со строчной буквы.
* Следите за долей: разнообразие по `env`, сезонам, времени суток, редкости; в каждой категории есть сцены только для лета/зимы/ночи и всесезонные.
